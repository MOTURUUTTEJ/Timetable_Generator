# Contributing to Timetable_Generator

Thanks for contributing! Please follow these guidelines to keep changes clear and maintainable.

## Development setup

1. Fork and clone the repository.
2. Open `Final_Timetable_Generater.html` in a modern browser.
3. Make focused changes and verify behavior manually.

## Contribution workflow

1. Create a feature/fix branch.
2. Keep commits small and descriptive.
3. Update documentation when behavior or usage changes.
4. Open a pull request with:
   - What changed
   - Why it changed
   - How it was tested

## Manual validation checklist

- Verify timetable generation still works for multiple branches.
- Verify faculty view/search still works.
- Verify JSON export and print output still work.

## Code style

- Prefer clear, readable JavaScript.
- Keep UI and logic changes minimal and focused.
- Avoid adding dependencies unless required.

## Reporting issues

When filing an issue, include:

- Browser and version
- Reproduction steps
- Expected behavior
- Actual behavior
- Screenshots (if UI-related)
