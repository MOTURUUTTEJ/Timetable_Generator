# Contributing to Timetable_Generator

Thanks for your interest in contributing! 🎉

## How to Contribute

1. Fork the repository.
2. Create a feature/fix branch from `main`.
3. Make focused, minimal changes.
4. Test your changes manually by opening `Final_Timetable_Generater.html` and validating key flows.
5. Commit with clear messages.
6. Open a Pull Request with:
   - Problem statement
   - What changed
   - Manual verification steps
   - Screenshots (for UI changes)

## Contribution Guidelines

- Keep changes small and scoped.
- Preserve the current single-file architecture unless a refactor is discussed first.
- Use clear naming and readable JavaScript.
- Do not commit secrets, generated files, or unnecessary assets.

## Bug Reports

When reporting bugs, include:

- Browser and version
- Reproduction steps
- Expected vs actual behavior
- Screenshot/recording if possible

## Feature Requests

Please describe:

- Use case/problem
- Proposed behavior
- Why it improves timetable generation workflow
