# Contributing Guidelines

Thank you for your interest in improving **Timetable_Generator**.

## Development Setup

1. Fork this repository.
2. Create a feature branch from `main`:
   ```bash
   git checkout -b feature/your-change
   ```
3. Open `Final_Timetable_Generater.html` directly in a browser for local testing.

## Contribution Standards

- Keep changes focused and minimal.
- Maintain the existing code style and naming patterns.
- Avoid adding new dependencies unless absolutely necessary.
- Ensure generated timetables still render in both Student and Faculty views.
- Verify Export JSON and Print features still work after your changes.

## Testing Checklist (Manual)

Before opening a pull request, verify:
- App loads without console errors.
- Branch selection and configuration flow works.
- Timetable generation completes successfully.
- Student/Faculty tab switching works.
- Faculty search works.
- JSON export works.
- Print/Save as PDF works.

## Pull Request Process

1. Update documentation when behavior changes.
2. Add a clear PR title and summary.
3. Keep commits meaningful and reviewable.
4. Ensure your PR addresses one concern at a time.

## Code of Conduct

Be respectful and constructive in all discussions and reviews.
